# SplitEase – Bill Splitter

SplitEase is a simple and responsive bill-splitting web application that helps users calculate the total bill and divide the amount equally among multiple people.

Users can enter the bill amount, number of people, tip percentage, and tax to instantly calculate the final amount and individual share.

## Features

* Enter total bill amount
* Select the number of people
* Add tax percentage
* Adjust tip percentage
* Quick tip selection buttons
* Automatic total bill calculation
* Calculate individual share
* Reset all values
* Responsive design
* Clean and user-friendly interface

## How It Works

1. Enter the total bill amount.
2. Select the number of people sharing the bill.
3. Choose the required tax percentage.
4. Select or adjust the tip percentage.
5. Click **Calculate**.
6. The application displays:

   * Original bill
   * Tax amount
   * Tip amount
   * Total bill
   * Amount per person
